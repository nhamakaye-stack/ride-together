# Ride Together UI

A responsive, polished user interface prototype for the Ride Together carpooling idea.

## Included screens and sections

- Onboarding / hero area
- Passenger trip search and matching cards
- Driver offer-a-lift form
- Safety and trust features
- Impact dashboard metrics
- Admin verification review panel

## Run locally

Open `index.html` directly in a browser, or serve it with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design direction

This prototype follows the concept of a Zambian smart-mobility platform focused on:

- route-based matching
- verified drivers and passengers
- safety and SMS/USSD-friendly access
- community and commuter corridor growth
- a greener, lower-congestion transport model
